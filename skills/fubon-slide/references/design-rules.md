# Applying the saved styles

Read `styles.json` as the canonical style source. Select exactly one style per deck, except when the user explicitly asks for separate named chapters with their own designs. Write the chosen rules, explicit user overrides, intended ratio, typography fallback, and page zones into `DESIGN.md` before building.

The tokens were extracted from user-owned teaching/communication references. They are visual approximations, not an official corporate brand manual. The public package contains no original training decks, product facts, proprietary logos, characters, or font binaries. Do not infer permission to upload a user's source materials from this package's public license.

Use the requested aspect ratio. Default `brand` to 16:9, and suggest 1:1 for `info`/`story` only when the user has not specified a ratio. Do not squeeze a 16:9 table into a square; restructure it. Keep visible product names and mandatory wording intact when using English production instructions.

Header/body/footer space must be reserved before arranging content. One page should carry one educational purpose. When the fixed slide count conflicts with legibility, shorten supplementary explanation or ask whether to split; do not silently drop product conditions or add pages.

For illustrations, choose the slot and allowed source before generation. Save real assets in `images/`, use meaningful filenames, and record them in the plan. Use supplied logos at their original proportions. If unavailable, use plain company text instead of drawing a new official logo. Tables, labels, and charts must remain real text in editable outputs.
