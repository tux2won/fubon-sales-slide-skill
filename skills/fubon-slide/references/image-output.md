# Sequential image output

Read the selected design and completed page prompts. Use the host's actual image-generation tool, one page at a time, in page order. Start from the reference assets/previous accepted page when the tool supports it. Preserve the chosen canvas ratio, exact visible copy, character continuity, palette, and footer safe area.

Save actual results as `page_01.png`, `page_02.png`, and so on, with the plan and prompts beside them. Inspect each generated page for altered Korean syllables, missing conditions, transposed numbers, illegible text, and changed visual style. Regenerate a failed page from its corrected prompt; do not silently accept a materially inaccurate condition.

If the image tool is absent or fails, report the concrete limitation and provide the page prompts for execution in a supported environment. Do not claim that an HTML screenshot is an AI-generated slide image. If the user requests a PPTX wrapper around generated images, explain that its embedded text and tables will not become editable PowerPoint elements.
