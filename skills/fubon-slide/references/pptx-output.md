# Editable PowerPoint output

Use the host's presentation-authoring capability and follow its required skill/workflow if available. This package supplies the design and layout plan, not a hidden PowerPoint application or a paid API. Do not require a particular unavailable library or install credentials. When no PPTX authoring capability exists, identify the missing tool and keep the plan/HTML available without mislabeling their file type.

Create native text boxes for titles, body copy, sources, and disclosures. Create native tables and data charts where supported. Use images only for approved illustrations or photographs. Apply the selected style tokens and the `DESIGN.md` page zones to masters or repeated layout objects. Preserve the requested page count, aspect ratio, exact numbers, units, and footnotes. Never flatten every slide into one picture when the user requested editable elements.

Render the resulting PPTX with an available presentation/PDF renderer and inspect every slide. Check text overflow, font substitution, table legibility, evidence labels, source mappings, and output editability. Report the actual `.pptx` file only after it exists; do not state that it was reviewed in PowerPoint unless it was.
