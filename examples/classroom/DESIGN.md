# Brand classroom

Brand classroom style, derived from a 27-page widescreen teaching deck and a two-page portrait leaflet. Use a white background, blue headings #0876B9, teal #13A5A1, dark text #222222, dark-gray table headers #444444, fine rules #D5DADF, and red #C00000 only for conditions or changes. These are observed approximations, not certified corporate CI values. Prefer legally available YouandiModern HeadRegular/HeadBold/HeadExtraBold and TextRegular/TextBold; fall back to Pretendard or Noto Sans KR. Use supplied original logos only. Cover: brand at the top left, title in a clear message zone, team and version below. Body: 12–15% header, 73–78% explanations/tables/diagrams, 10–12% sources and disclosures; outer margins about 4–5%. Keep title and footer axes stable. Use full-width tables, parallel comparisons, product-structure diagrams, or purposeful feature groups. Tables use dark headers with white labels, fine separators, explicit units and bases, and restrained row emphasis. Charts use blue/teal with accurate proportions. For 16:9 PPT, target 28–32pt headings, 18–22pt body, 14–18pt table text, and 9–11pt notes, adjusting layout before shrinking. Portrait leaflets follow brand/product name → key explanation → diagram/table → scenario assumptions → disclosures; distinguish the original 7.5:10.833 ratio from A4. Teal section dividers and a restrained white closing are permitted. Avoid excessive shadows/3D ornament, lost conditions, and inherited old product numbers.
