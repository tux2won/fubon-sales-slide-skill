# Provided brand assets

The Youandi Modern OTF font files and Fubon Hyundai Life logo PNGs in this folder were supplied by the user for the requested website branding and repository update. They are preserved as provided, with ASCII filenames for reliable web URLs.

These assets retain their original rights and are excluded from this repository's Apache-2.0 software license. Their inclusion does not grant a new license to the fonts, corporate marks, or artwork. The installable `fubon-slide` skill remains a separate package of production rules and templates; it does not bundle these website assets.
